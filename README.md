# 명퇴시계

퇴직까지 남은 날을 세는 개인용 웹 앱(PWA). 홈 화면에 추가하면 앱처럼 열리고, 한 번 열어 두면 인터넷 없이도 동작합니다.

## 화면

- **홈** — 3대 일정(명퇴 가능 · 1차 퇴직 · 최종 명퇴)까지 남은 날, 출근일·주말·월급날·개월 수, 오늘의 요약
- **달력** — 월별 달력에 공휴일·일정 표시, 날짜별 메모
- **자산** — 현재 금융자산과 월 저축·수익률로 10억·60억 도달 시점 계산
- **삼원칙** — 건강 · 돈 · 일상, 날짜별 체크와 한 줄 기록
- **설정** — 테마, 기준 시작일, 생년월일(만 나이 표시용), 급여일, JSON 백업/복원

## 저장

메모·자산·체크 기록과 설정은 브라우저 localStorage에만 저장됩니다. 서버로 보내지 않습니다.
기기를 바꾸거나 브라우저 데이터를 지우면 사라지므로 설정의 **JSON 내보내기**로 가끔 백업하세요.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 본체 (HTML·CSS·JS 단일 파일) |
| `manifest.webmanifest` | 앱 이름·아이콘·테마, 홈 화면 설치 정보 |
| `sw.js` | 오프라인 캐시용 서비스 워커 |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |

## 공휴일 데이터

관공서의 공휴일에 관한 규정(2026.5.11. 시행) 기준이며, 2028년 이후는 현행 규정으로 계산한 예상치입니다.
임시공휴일과 선거일은 포함하지 않았습니다.
